# 小咩后台研究｜第六章接入

## 使用

运行 `uv run python main.py`，仍然进入原终端界面。启动过程自动启动本机研究服务；不需要手动开第二个终端，不占用课程实验的 2024 端口。

- “后台研究 LangGraph 的 thread 和 run 区别，保留官方来源，先返回任务 ID。”
- “研究继续，先解释一下什么是接口约定。”
- “追加要求：只看官方文档。”
- “查询刚才研究的最新状态；完成了就展示结果和来源。”
- “取消刚才的后台研究。”

第一版每段会话最多一个活跃后台研究；模型一次请求启动两个任务时，程序也会拒绝第二个。没有自动轮询通知，不把历史状态当作最新状态。

`Esc` 停止当前回复，后台研究仍可查询或取消。`/clear` 清空聊天展示但保留后台任务记录。退出小咩会停止自己启动的研究服务；本版不提供跨应用重启恢复。取消不能撤销已经发出的外部搜索请求。

## 代码与课程对应

| 位置 | 责任 |
| --- | --- |
| `app/researcher.py` | 独立研究图，复用现有模型配置，仅授予搜索工具，保留来源与资料局限要求 |
| `app/agent.py` | 注册 `AsyncSubAgent`，由官方五个异步工具委派和管理研究 |
| `app/research.py` | 限制一个活跃任务，登记工具回执，保留任务说明，核对取消终态；清理研究员中断后未配齐结果的工具调用 |
| `app/research_server.py` | 启动本机随机端口服务，退出时清理自己拥有的进程与临时运行目录 |
| `app/tui.py` | 继续使用原有聊天、审批和错误处理；每轮注入独立任务账本，展示真实工具返回 |

终端主 Agent 仍在客户端进程中，研究员运行在 Agent Server，通过本机 HTTP 调用。保留这一边界可以复用现有终端审批与流式事件处理。使用 Studio 时，`langgraph.json` 同时注册 `mie` 与 `researcher`，两者走进程内 ASGI。

终端的主图临时检查点仍在每轮结束后清理，避免重放停止或未批准的操作。`async_tasks` 来自独立的进程内任务账本，成功的任务管理回执在主回复结束前登记；下一轮可找回任务，不依赖聊天里是否保留了 ID。Studio 则使用服务端主线程状态，不在不同会话之间共用任务账本。

启动后立刻更新时，旧 run 可能尚未持久化原始输入，因此更新会显式携带原始主题和历次补充。更新若打断了模型工具调用，未配齐结果的调用组会在研究员下一次模型调用前移除，保留用户要求和完整证据，不伪造工具成功结果。

## 验证记录｜2026-09-28

本次实现由助手按用户明确授权完成，不计为学习者独立实现。

- 修改前：24 项终端、审批、工具详情基线回归通过。
- 集成后：85 项全量自动化测试通过。后台测试使用真实本地 Agent Server 和官方异步工具，模型与搜索采用离线替身。
- 覆盖启动后子 run 仍在 pending/running、继续聊天、同 task 新 run、原主题与追加要求到达子图、结果来源返回、单任务限制（含并行启动请求）、取消的服务端终态、Esc/失败后任务保留及 `/clear` 后重新查询。
- 中断恢复测试确认仅移除不完整工具调用组，保留完整工具证据与用户消息，不重放未完成操作。
- 最后调整失败回复的恢复提示后，另跑 6 项定向测试通过；不将两次测试计数合并为一次全量结果。
- 真实模型与 Tavily 验证：主 Agent 实际依次调用 start、update、check；中间一轮普通聊天无工具调用；启动后服务状态为 pending；更新 task 不变而 run 改变；最终服务状态 success。研究线程中观察到实际 internet_search 返回，最终使用的官方链接存在于该搜索结果中。
- 真实研究刻意限制搜索次数，因此只验证链路和来源对应，不宣称研究全面性；回答保留了“run 定义缺乏独立官方条目”的资料局限。
- `main.py --plain` 实际启动并输入 `/exit` 成功退出；验证进程会清理自己启动的服务。真实模型验证记录见 [live-research.json](evidence/ch06/live-research.json)。

测试命令：

```bash
uv run python -m unittest discover -s tests -t . -q
```

依赖锁没有升级现有库版本；将原本的开发用 Agent Server 依赖提升为运行依赖，并显式声明已有的 SDK 版本。

## 边界

- 不支持跨应用重启恢复、远程部署、多后台研究并发或自动通知。
- 终端用量面板统计主 Agent 本轮事件，不包含独立研究员的全部 token。
- `success` 是执行终态，不能替代研究内容与来源质量验收。
- SDK 原生异步客户端在测试事件循环退出时可能报告未关闭连接的 ResourceWarning；本次测试通过且服务进程已清理，但这不等同于长时间资源稳定性验证。
